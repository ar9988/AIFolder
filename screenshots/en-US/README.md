# English Google Play assets

The six phone screenshots are actual captures of TagFile 1.1.8 running in English on the Pixel 7 Android emulator, at 1080 × 2400 pixels. They correspond to the Korean filenames in the parent directory.

- `file_dashboard.png`: file dashboard and recently used tags.
- `file_listview.png`: Documents / Receipts, with receipt tags.
- `tag.png`: tag list.
- `setting.png`: indexing preferences and Strict search matching.
- `assistant_result.png`: English receipt search and six matching files.
- `starter_tags.png`: starter tag suggestions on a fresh temporary Android user.

The two feature graphics are 1024 × 500 PNGs. Use either graphic in the English store listing's feature graphic field. The phone screenshots belong in the phone screenshots field.

Feature graphics were localized using the built-in imagegen tool with the Korean banner as the edit target and the actual English screenshots as supporting images, then resized to 1024 × 500. Generated phone previews can contain small rendering differences; the six standalone captures are unedited emulator screenshots.

Localization instructions used for both graphics: preserve the original navy gradient, teal accents, left-aligned text hierarchy, checklist, and two phone frames on the right; replace Korean copy with the English copy below and use the corresponding English phone captures.
